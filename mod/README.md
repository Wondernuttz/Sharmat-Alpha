# SHARMAT 3.1.1 - Feature Update

**Update both the SHARMAT server and game mod for this feature update.**
The complete [3.1.1 game package](https://github.com/Wondernuttz/Sharmat-Alpha/releases/download/v3.1.1/SHARMAT-3.1.1.zip)
includes the updated game scripts and matching embedded server extension.
See [installation instructions](README.txt).

This release adds optional Devious Devices awareness and confirmed lock/unlock
actions. Settings and editable prompts are under **Prompts → Devices & Wearables**;
per-action enablement and confirmation use CHIM's existing Actions editor.

Device actions use DD 5.2 NG APIs. Put a single device variant in the wearer's
inventory; unlocking requires matching keys. Relationship gates apply to locking;
helping remove a device does not require romance. Quest devices, special locks and
conflicting equipment remain controlled by their own mods. DD is not required
for the existing OStim/SexLab functionality.
